# Sistema de Estoque

Sistema de linha de comando para cadastro de produtos, desenvolvido em Java como prática de lógica de programação, estruturas de repetição e Orientação a Objetos. 

## Funcionalidades

- Cadastro de produtos (nome, preço e quantidade);
- Cálculo automático do valor total em estoque;
- Exibição formatada dos produtos cadastrados;

## Como executar

1. Clone o repositório
2. Compile e execute a classe "Main"
3. Informe a quantidade de produtos e cadastre um por um
